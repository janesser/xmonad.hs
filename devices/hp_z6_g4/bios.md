# manual installation via usb-media

* download bios https://support.hp.com/de-de/drivers/hp-z6-g4-workstation/16449901
* format of usb-media must be FAT32
* BIN file in path exactly "EFI/HP/BIOS/New"

enter bios via F1 -> ESC -> BIOS update from file

* several reboots and some patience later, it completes
